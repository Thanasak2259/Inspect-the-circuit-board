# รายงานการทดสอบ PCB Inspection v1.0

สร้างอัตโนมัติด้วย `python benchmark/run_benchmark.py` (66 ภาพทดสอบ, ผลซ้ำได้ทุกครั้ง)

## F2 — จัดแนวภาพเอียงด้วย ORB + Homography

ใส่การเอียง/มุมมอง (perspective) ที่ทราบค่าจริงลงในภาพ แล้ววัดว่าหลังจัดแนวด้วย ORB + RANSAC ตำแหน่งคลาดเคลื่อนกี่พิกเซล

| เอียง (องศา) | ไม่จัดแนว (px) | ORB + Homography (px) |
|---|---|---|
| 0 | 0.0 | 0.00 |
| 3 | 12.8 | 0.25 |
| 6 | 25.2 | 0.22 |
| 10 | 40.8 | 0.30 |
| 15 | 59.4 | 0.36 |
| 20 | 77.5 | 0.49 |

จัดแนวล้มเหลว 0 จาก 18 กรณี  (กราฟ: `alignment_error.png`)

ผลคือถ่ายภาพเอียงด้วยกล้องทั่วไปก็ตรวจได้ ไม่ต้องใช้แท่นล็อกชิ้นงาน (jig) ตราบใดที่ภาพยังเห็นทั้งบอร์ดและมีลายให้จับคู่ได้

## F3 — ชุดข้อมูลทดสอบที่ท้าทาย

3 บอร์ด (เขียว / ดำ / แดง) รวม 17 ชิ้นส่วนที่ถูกถอดออก ครอบคลุมสภาพที่ยาก:

- **แสงสะท้อนบนจุดบัดกรี** (`glare`): จุดสว่างจัดแบบ specular 6 จุดต่อภาพ ตำแหน่งสุ่ม
- **ชิ้นส่วน SMD เล็กสีกลืนกับบอร์ด**: บอร์ดดำที่ชิ้นส่วนเป็นสีดำบนพื้นดำ (`black`)
- แสงสว่าง/มืด/อุ่น/แกมมา/แสงไม่สม่ำเสมอ, สัญญาณรบกวน, JPEG คุณภาพต่ำ
- บอร์ดเอียง (`tilt`) และเอียงร่วมกับแสงสะท้อน (`tilt+glare`)
- ทุกเงื่อนไขมีภาพควบคุม **ไม่มีข้อบกพร่อง** คู่กัน เพื่อวัดการเตือนผิด

## F4 — Absolute Difference เทียบกับ SSIM

ทั้งสองวิธีใช้ภาพที่จัดแนวแล้วชุดเดียวกัน, เบลอ Gaussian 5×5 เท่ากัน, ขั้นตอนสร้างกรอบเท่ากัน และ**ปรับ threshold บนสภาพแสงปกติเท่านั้น** (AbsDiff = 84, SSIM = 182) แล้วนำไปใช้กับทุกเงื่อนไขโดยไม่ปรับซ้ำ เพื่อดูว่าวิธีไหนทนต่อการเปลี่ยนแสงได้จริง

|---|---|---|---|---|---|---|

| warm | 0.68 | 0.72 | 1.00 | 0.0 | 0.0 | 0.0 |
| gamma | 0.59 | 0.61 | 0.94 | 0.0 | 3.0 | 0.0 |
| uneven | 0.61 | 0.77 | 0.91 | 0.7 | 0.0 | 0.0 |
| glare | 0.56 | 0.65 | 0.92 | 3.7 | 4.0 | 5.0 |
| noise | 0.70 | 0.74 | 0.97 | 0.0 | 0.0 | 0.0 |

ตัวชี้วัด: Precision / Recall / F1 นับว่า "เจอ" เมื่อกรอบอยู่ห่างจากชิ้นส่วนที่ถอดจริงไม่เกิน 60 px (หนึ่งชิ้นส่วนจับคู่ได้หนึ่งครั้ง) และ FP/ภาพไม่มีตำหนิ = จำนวนกรอบที่ขึ้นบนภาพที่ไม่มีอะไรเปลี่ยนเลย

## สรุปผล

- **SSIM ดีกว่า Absolute Difference** ในภาพรวม (F1 0.67 เทียบ 0.60) เพราะเทียบโครงสร้างของภาพ จึงไม่ถูกหลอกง่ายเมื่อแสงไม่สม่ำเสมอหรือภาพเอียงเล็กน้อย แต่ SSIM ไวต่อการเปลี่ยนความสว่างรวม (dark/gamma) ทำให้เตือนผิดเพิ่ม ส่วน Absolute Difference เสียความแม่นยำที่สุดเมื่อภาพมืด
- ทั้งสองวิธีเดี่ยวๆ ยังไม่พอใช้งานจริง: F1 รวม 0.60 / 0.67 เทียบกับ pipeline ของโปรแกรม 0.96 ซึ่งเพิ่มการปรับความสว่าง/สีอัตโนมัติ, ยอมให้ขอบเลื่อนเล็กน้อย, ตรวจว่าตำแหน่งนั้น 'เหลือแต่บอร์ด' จริง และกรองกรอบเล็ก/บางที่เป็นสัญญาณรบกวน

## ข้อจำกัดที่พบจากการทดสอบ (ไม่ปิดบัง)

- **แสงสะท้อนจัด (glare)**: pipeline ยังขึ้นกรอบผิดบนจุดสะท้อนแรง (เฉลี่ย 5.0 กรอบ/ภาพที่ไม่มีตำหนิ ในชุดทดสอบที่ใส่จุดสะท้อน 6 จุด) ผมลองกรองจุดสะท้อนด้วยความสว่าง/ขอบนุ่ม แล้วพบว่าแยกไม่ขาดจากแผ่นทองแดงที่เพิ่งเผยหลังถอดชิ้นส่วน ซึ่งทำให้ตรวจชิ้นส่วนจริงพลาด จึงไม่ใส่ไว้ แนะนำให้ถ่ายด้วยแสงกระจาย หรือใช้โพลาไรเซอร์
- การทดสอบชิ้นส่วนที่ถูกถอดใช้ภาพตัวอย่าง 3 บอร์ด (17 ชิ้นส่วน) เงื่อนไขแสง/เอียง/สัญญาณรบกวนจำลองด้วยโค้ด ยังไม่ใช่ภาพถ่ายจริงจากหน้างาน
- การทดสอบ F2 บังคับใช้ ORB อย่างเดียว ส่วนตัวโปรแกรมจริงลอง SIFT ก่อนแล้วค่อยใช้ ORB สำรอง
